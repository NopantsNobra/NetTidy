## 详细使用教学

### 面向小白用户的完整教程

#### 📦 安装与目录结构

```
1. 下载整个 folder_restructure_v8/ 文件夹
2. 将其放到任意位置（如 D:\Tools\）
3. 目录结构应包含：
   folder_restructure_v8/
   ├── __init__.py
   ├── __main__.py
   ├── 命令行接口.py      ← 主入口
   ├── 常量定义.py
   ├── 数据模型.py
   ├── ...
   └── 单元测试.py
```

#### 🚀 快速开始（3步曲）

**第一步：进入工具所在目录的父目录**
```bash
# 假设工具在 D:\Tools\folder_restructure_v8\
# 需要进入 D:\Tools\ 目录
cd D:\Tools

# 然后使用 python -m 运行
```

**第二步：诊断（只看不改）**
```bash
python -m folder_restructure_v8 D:\MyFolder --diagnose
```
输出示例：
```
===============================================================
  文件夹整理工具 V8.0.0
===============================================================
📂 扫描目录: D:\MyFolder
  📄 文件: 1234
  📁 目录: 56
  💾 大小: 5.6 GB
  👁️ 隐藏: 12
  🔒 只读: 3
```

**第三步：预览并执行**
```bash
# 交互式选择（推荐小白使用）
python -m folder_restructure_v8 D:\MyFolder --preview-interactive

# 或直接执行（首次建议加 -y 跳过确认确认）
python -m folder_restructure_v8 D:\MyFolder --execute -y
```

#### 📋 常见使用场景

| 场景 | 命令 |
|------|------|
| **清理下载文件夹** | `python -m folder_restructure_v8 D:\Downloads --preview-interactive --execute` |
| **清理项目缓存** | `python -m folder_restructure_v8 D:\Projects --only-cache --only-dedup --execute -y` |
| **照片按日期分组** | `python -m folder_restructure_v8 D:\Photos --flatten-by date --execute` |
| **代码按类型分组** | `python -m folder_restructure_v8 D:\Assets --flatten-by ext --execute` |
| **生成报告** | `python -m folder_restructure_v8 D:\Shared --preview --html-report report.html` |
| **修复下载文件权限** | `python -m folder_restructure_v8 D:\Downloads --only-perm --fix-attr all --execute` |
| **用回收站删除** | `python -m folder_restructure_v8 D:\Temp --use-recycle-bin --execute -y` |
| **硬链接去重省空间** | `python -m folder_restructure_v8 D:\Videos --only-dedup --dedup-strategy hardlink --execute -y` |

#### 🔧 进阶用法

**生成自定义配置：**
```bash
# 生成配置文件模板
python -m folder_restructure_v8 --init-config

# 编辑 restructure_config.json 后使用
python -m folder_restructure_v8 D:\Project --config restructure_config.json --execute
```

**自定义缓存清理规则：**
```bash
# 追加额外要清理的模式
python -m folder_restructure_v8 D:\Project --extra-patterns "*.log" "temp_*" --execute

# 或修改配置文件
# restructure_config.json 中添加：
# "cache_patterns": [..., "自定义目录"]
```

**离线分析（不需要 Windows）：**
```bash
# 在 Windows 上导出文件列表
(Get-ChildItem -Path 'E:\' -Recurse -Force).FullName | Out-File 'list.txt' -Encoding UTF8

# 在任何平台上分析
python -m folder_restructure_v8 --from-list list.txt --html-report report.html
```

#### 🛡️ 安全机制说明

| 保护措施 | 说明 |
|---------|------|
| **预览模式** | 默认只预览，不实际执行 |
| **回收站** | 所有删除实际移入 `.restructure_trash/` |
| **回滚脚本** | 执行后自动生成 `rollback.py` |
| **系统回收站** | 可选使用 Windows 回收站（可用右键还原） |
| **锁文件** | 防止多进程同时操作同一目录 |

#### 📁 生成的文件

执行后会生成以下文件（都在目标目录内）：

```
D:\MyFolder\
├── .restructure_trash/     ← 删除的文件临时存放
├── .restructure_logs/       ← 操作日志
│   ├── operations_*.jsonl  ← 详细操作记录
│   └── rollback.py          ← 回滚脚本（可恢复操作）
```

**回滚操作：**
```bash
cd D:\MyFolder
python .restructure_logs\rollback.py
```

#### ⚠️ 注意事项

1. **首次使用建议**：先 `--diagnose` 查看目录情况
2. **谨慎目录**：系统目录（Windows、Program Files）会被保护
3. **重要数据**：操作前建议备份，或先只用 `--preview` 预览
4. **管理员权限**：遇到权限错误时，尝试以管理员身份运行

#### 🔍 故障排查

| 问题 | 解决方法 |
|------|---------|
| `ModuleNotFoundError` | 确保在包**父目录**执行 `cd ..` |
| "目录被锁定" | 等 12 小时或加 `--force-lock` |
| 权限错误 | 右键 → 以管理员身份运行 |
| 误删文件 | 运行 `python .restructure_logs\rollback.py` 或在 `.restructure_trash/` 找 |
| 想恢复回收站文件 | 打开桌面回收站，右键"还原" |
