## 已落实的安全控制

- 默认试运行：`build_plan()` 只读取文件系统并生成冻结 `OperationPlan`，不修改磁盘。
- 边界保护：批量模式只整理运行根目录下的直接子文件夹；运行根目录文件只记录为 `IGNORED_ROOT_FILE`。
- 单资源保护：单资源模式中文件最高只提升到所选目录内部。
- 不跨资源根：每个资源根独立建树、独立生成目标路径。
- 不静默覆盖：执行前 `precheck()` 对已存在目标抛出 `TARGET_CONFLICT`。
- copy 源安全：copy 模式验证输出目录不与源目录互相包含，执行只复制文件。
- move 显式确认：CLI move 必须传入 `--confirm`，执行器也要求 `confirm_move=True`。
- move 可追踪：move/rmdir 写入 `transaction_log.jsonl`。
- Windows move 默认请求管理员权限；可用 `--no-elevate` 保持当前权限执行。
- 提供 `undo transaction_log.jsonl`，按事务日志尽力撤销已完成 move，遇到原路径已存在会拒绝覆盖。
- 本地 Web：默认只允许绑定 `127.0.0.1`。
- 排除特殊项：符号链接、Windows reparse point、系统文件、理巢报告/输出目录、明显未完成下载文件会跳过并记录异常。
- 文件名清洗：计划阶段处理 Windows 非法字符、保留名、尾随空格/点号和过长名称。
- 重复文件诊断只生成报告，不自动删除、移动或合并。
- 主动权限修复默认关闭，只有用户勾选或 CLI 指定参数时才执行。
- 操作历史写入本地 SQLite，不联网、不上传。
- Web 表格限制展示前 500 条，完整映射通过报告导出，避免大规模目录导致 UI 卡死。
