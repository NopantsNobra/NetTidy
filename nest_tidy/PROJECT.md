## 一、产品概述

### 1.1 是什么

理巢（NestTidy）是一个**智能目录清理工具**，解决的核心问题：

> 从网盘、BT、压缩包等渠道下载的资源文件夹，往往嵌套了大量无意义的"新建文件夹"层级。理巢通过确定性算法自动剥离这些冗余嵌套，输出扁平、干净的目录结构。

### 1.2 典型场景

- 百度网盘/阿里云盘下载的剧集合集，套了 3-4 层"新建文件夹"
- BT 下载的番剧/漫画，打包者目录习惯各异
- zip/rar 解压后的混乱层级
- 跨设备迁移后文件带只读/隐藏/网络标记等属性问题

### 1.3 技术栈

| 项 | 选型 |
|:--|:--|
| 语言 | Python 3.9+ |
| UI | Streamlit（单页面 Web 应用） |
| 目标平台 | Windows 10/11 |
| 第三方依赖 | 仅 `streamlit`（+ `pytest` 用于测试） |
| 核心依赖 | 全部标准库（pathlib, shutil, subprocess, ctypes, hashlib） |

## 三、核心算法（R0-R5）

这是产品的核心价值所在。六条规则按固定顺序执行，每一步行为可预测、可解释。

### 执行顺序

```
R0 前置清理 → R1 直链穿透 → R2 壳吸收 → R3 分叉口判定 → R4 单文件提级 → R5 撞名重命名
```

### 规则速查

| 规则 | 名称 | 触发条件 | 动作 |
|:--|:--|:--|:--|
| **R0** | 前置清理 | 永远执行 | 自底向上递归删除空目录 |
| **R1** | 直链穿透 | 根有1个壳子目录，且壳链终止于文件（非分支） | 消除整条壳链，终止点内容提升到根 |
| **R2** | 壳吸收 | 当前节点的子目录是壳（0文件+1子目录） | 反复将唯一子目录内容上移，保留壳名 |
| **R3** | 分叉口判定 | 子目录数≥2，当前目录无文件 | 根层级：全留+冻结递归；非根：全提或全留 |
| **R4** | 单文件提级 | 未冻结的子目录只有1个文件 | 文件提取到父级，删除子目录 |
| **R5** | 撞名重命名 | 同层出现同名项 | 沿 source_path 追溯不同名祖先，前缀重命名 |

### 关键设计决策

- **`source_path` 字段**：TreeNode 同时持有 `path`（当前位置）和 `source_path`（算法前原始位置）。R2/R3 移动节点时不更新 `path`，R5 用 `source_path` 做祖先追溯，避免路径信息丢失。
- **R1 保守触发**：当壳链终止点的子目录全是单文件叶子时，R1 不触发，交给 R3 的全提+撞名处理。这保证了 TC-15（壳吸收后全提导致撞名）的正确性。
- **R4 根层级保护**：根有文件时 R4 不在根层执行，防止误提子目录文件。

### 术语表

| 术语 | 定义 |
|:--|:--|
| 壳 | 0文件 + 恰好1个子目录的目录 |
| 分叉口 | 0文件 + ≥2个子目录的目录 |
| 冻结 | 标记后不参与 R4，但 R0-R3 在内部仍正常执行 |
| 映射表 | source_path → target_path 的完整对应关系 |

## 五、Web UI 设计

### 5.1 四步流程

```
Step 1 配置        Step 2 扫描&算法     Step 3 预览对比      Step 4 执行
┌──────────┐      ┌──────────────┐     ┌──────────────┐    ┌────────────────┐
│ 源目录    │─────▶│ 扫描目录树   │────▶│ 原树 vs 新树 │───▶│ 复制/移动       │
│ 目标目录  │      │ 运行 R0-R5   │     │ 差异高亮     │    │ 权限修复       │
│ 策略选择  │      │ 生成映射表   │     │ 用户确认     │    │ 结果日志       │
│ 权限修复  │      └──────────────┘     └──────────────┘    └────────────────┘
└──────────┘
```

### 5.2 Session State 键

| 键 | 类型 | 说明 |
|:--|:--|:--|
| `step` | int | 当前步骤 1-4 |
| `source_dir` / `target_dir` | str | 路径 |
| `strategy` | str | copy / move / auto |
| `fix_perm` / `fix_readonly` / `fix_hidden` / `fix_zone` | bool | 权限修复开关 |
| `scan_tree` / `result_tree` | TreeNode | 扫描树/结果树 |
| `mapping` | dict | 映射表 |
| `diff_report` | DiffReport | 差异报告 |
| `execution_log` | dict | 执行结果+权限修复结果 |
