5 进阶：清理缓存 + 去重一条龙

进阶 默认就会清理缓存目录和去重。你还可以自定义。

追加自定义缓存模式

📋 场景：除了内置的 30+ 种缓存目录，你想额外清理 "my_build" 和 "temp_output"
D:\tools> python 文件夹重组工具V6.0.py D:\Projects --extra-patterns "my_build" "temp_output" --preview

选择去重保留策略

策略参数效果
shallowest（默认）--dedup-strategy shallowest保留目录层级最浅的文件（通常是最"原始"的位置）
newest--dedup-strategy newest保留最后修改时间最新的文件
D:\tools> python 文件夹重组工具V6.0.py D:\Projects --dedup-strategy newest --execute -y

去重原理（三级哈希，V6.0 使用 SHA256）

按文件大小分组 → 前 4KB SHA256 → 完整文件 SHA256 → 标记删除

只有三个阶段都匹配的文件才会被判定为重复。V6.0 升级为 SHA256，碰撞概率可忽略不计。

6 进阶：层级扁平化

进阶 V6.0 新增 把深层嵌套的文件全部提取到一个平铺目录中。

📋 场景：把散落在 10 层子目录里的所有 PDF 提取到一个文件夹

提取全部文件到默认目录（_flattened）

D:\tools> python 文件夹重组工具V6.0.py D:\Projects --flatten --execute -y
  📦 扁平化: 提取 892 个文件到 D:\Projects\_flattened

提取到指定目录

D:\tools> python 文件夹重组工具V6.0.py D:\Projects --flatten D:\AllPDFs --execute -y

冲突解决

如果有同名文件，自动追加来源目录名：

🔴 扁平化前

  • D:\Projects\a\config.json
  • D:\Projects\b\config.json
  • D:\Projects\c\d\config.json

🟢 扁平化后

  • D:\AllPDFs\config.json
  • D:\AllPDFs\config_from_b.json
  • D:\AllPDFs\config_from_d.json
💡 扁平化前建议先用 --preview 看看会提取多少文件。也可以先用 --diagnose 了解目录结构。

8 进阶：离线分析

进阶 不在 Windows 上？只需要一个文件列表，就能做完整的诊断分析。

第一步：在目标机器上导出文件列表

推荐方式（不会截断长路径）：

PS C:\> (Get-ChildItem -Path 'D:\' -Recurse -Force).FullName | Out-File 'list.txt' -Encoding UTF8

或者用自定义格式（更精确，包含深度和类型）：

PS C:\> # 自定义格式，自动标记目录/文件
Get-ChildItem -Path 'D:\Projects' -Recurse -Force | ForEach-Object {
    $depth = ($_.FullName -split '\\').Count - 2
    $type = if ($_.PSIsContainer) { 'DIR' } else { 'FILE' }
    "[{$depth}] $($_.FullName) #$type"
} | Out-File 'list_custom.txt' -Encoding UTF8

自定义格式长这样：

[{0}] D:\Projects #DIR
[{1}] D:\Projects\src #DIR
[{2}] D:\Projects\src\main.py #FILE
[{2}] D:\Projects\src\utils.py #FILE
[{1}] D:\Projects\tests #DIR

第二步：在任意系统上运行分析

10 高级：多线程调优

高级 V6.0 默认使用 min(8, CPU核心数) 个线程。你可以手动调整。

场景推荐线程数命令
SSD + 大量小文件8 ~ 16--threads 12 或 -j 12
HDD 机械硬盘2 ~ 4-j 2
默认（自动检测）自动不加 --threads
# SSD 上使用 16 线程加速
D:\tools> python 文件夹重组工具V6.0.py D:\BigProject --execute -j 16 -y

# HDD 上保守使用 2 线程
D:\tools> python 文件夹重组工具V6.0.py E:\OldDisk --execute -j 2 -y

哪些阶段会并行？

目录扫描（单线程） → Zone 检测（多线程） → 哈希去重（多线程） → 移动/删除（多线程）

13 常见问题

Q: 我不小心删了重要文件，怎么办？

别慌。所有"删除"都在 .restructure_trash/ 里：
① 运行 python .restructure_log\rollback.py 回滚全部操作
② 或者手动从 .restructure_trash\ 复制你需要的文件

Q: 工具说"目录被锁定"怎么办？

D:\tools> python 文件夹重组工具V6.0.py D:\Projects --force-lock --execute

Q: 我只想看看有多少重复文件，不想删？

D:\tools> python 文件夹重组工具V6.0.py D:\Projects --preview
  # 会显示重复文件清单，但不会修改任何文件

Q: 为什么离线模式的重复文件显示 0 项删除？

V6.0 的安全改进：离线模式如果没有文件大小数据，同名文件 不会被自动标记删除，而是标记为"同名疑似重复，请手动确认"。这是为了避免 1GB 视频和 1KB 空文件被误判为重复。

Q: HDD 上跑得太慢？

# 机械硬盘建议减少线程数
D:\tools> python 文件夹重组工具V6.0.py E:\Data --execute -j 2 -y

Q: 路径被截断警告

用 PowerShell 重新导出（不会截断）：

PS C:\> (Get-ChildItem -Path 'D:\' -Recurse -Force).FullName | Out-File 'list.txt' -Encoding UTF8

Q: 可以在 Linux/Mac 上用吗？

在线模式（直接操作文件）：仅支持 Windows。
离线模式（--from-list）：任意平台，只需要 Python 3.9+。
先在 Windows 上导出文件列表，然后拷贝到 Linux/Mac 上分析。
